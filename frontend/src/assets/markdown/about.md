# About mdit

mdit is a desktop Markdown viewer/editor built with Go and Wails.

This application is written by an AI coding agent.

This software is free and open source. You use it at your own risk, without warranty of any kind.

## Keyboard Shortcuts

- `Ctrl/Cmd + K` - Command palette
- `Ctrl/Cmd + N` - New document
- `Ctrl/Cmd + O` - Open file
- `Ctrl/Cmd + S` - Save active tab
- `Ctrl/Cmd + W` - Close active tab
- `Ctrl/Cmd + Tab` - Next tab
- `Ctrl/Cmd + Shift + Tab` - Previous tab
- `Ctrl/Cmd + Z` - Undo in active tab
- `Ctrl/Cmd + Shift + Z` - Redo in active tab
- `Ctrl/Cmd + Y` - Redo in active tab
- `Ctrl/Cmd + F` - Find in preview
- `Ctrl/Cmd + E` - Cycle Editor / Split / Preview
- `Ctrl/Cmd + B` - Toggle sidebar
- `Alt + Z` - Toggle word wrap
- `F1` - Markdown cheat sheet
- `Ctrl/Cmd + Q` - Quit
